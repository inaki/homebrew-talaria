# homebrew-talaria

Homebrew tap for [Talaria Agent](https://github.com/inaki/talaria), an unofficial native TUI host for [Hermes Agent](https://github.com/NousResearch/hermes-agent).

```bash
brew install inaki/talaria/talaria
```

Not affiliated with or endorsed by Nous Research. Live mode uses the same `~/.hermes` as `hermes --tui`; quit the other TUI first.
